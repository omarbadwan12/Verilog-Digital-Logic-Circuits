Verilog Digital Logic Circuits Design

Digital Systems (ENCS2340) project part 2 at Birzeit University

Overview
This project involves designing and simulating various combinational logic circuits using Verilog HDL and Altera Quartus II

 Implemented Circuits
1. 1-Bit Comparator
2. 4-Bit Comparator
3. Full Subtractor
4. 2-to-4 Decoder
5. 4-to-1 Multiplexer
6. Top-Level Circuit (Decoder and Multiplexer integration)
